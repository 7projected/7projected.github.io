Projects

Custom C# and Monogame Framework

This framework is one of the largest and most technically challenging projects I've built.

It handles many core systems required for game development, including
rendering, buffering, asset loading, tilemaps, sprites, transforms, cameras, debugging tools, and more.

I plan on continuing to work on it as I continue to make games, and apps.
It is fully open source, and I am currently working on cleaning it up, and writing documentation for it.

Simple Tilemap Tool

I made this app in a short period of time as well, but it has served me well.
I used to frequently use this app to create maps for games before I found out how to use Tiled.

It is a very basic tool, it saves and loads files to its own file type.
The first two lines of the file are width and height.
The rest is a hexadecimal map of tile indexes.

The tool also has its own tileset generator. You input an image and some fields and it creates a tileset file.
